WHAT IS CUT, AND WHY
regex over names and features. Fuzzy already finds athjs → src/auth.js. Regex there is a worse tool for the same job.
whole word as its own mode. It is \b in a regex you are already typing.
glob over a single buffer. One file has no paths to filter.
quickfix as a third view. The tree does the same job and is already bound.
cwd separate from root. Two scopes that differ only when you have wandered; one key, root, and the tree for the exception.
