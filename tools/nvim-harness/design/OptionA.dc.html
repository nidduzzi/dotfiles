Option A
A key per target, modes on chords
What exists today, with the collisions fixed. You choose the target before opening; everything else is an Alt chord inside.
ENTRY
<leader>sg
file contents
<leader>ff
file names
<leader>?
editor features and keymaps
<leader>sb
lines in this buffer
INSIDE THE PICKER
<c-g>
freeze the search, fuzzy filter what came back
<a-r>
regex or fixed string
<a-s>
cycle scope: code, everything, documentation
<a-e>
extensions
<a-G>
path glob, ! to exclude
<c-t>
same results, as a tree
FOR IT
Fewest keystrokes for the common case: two keys and type. No mode to notice, nothing to undo. Every capture in the tour was driven this way, so it is known to work.
AGAINST IT
Six chords to remember, and the state they set is invisible until you read the title. Pivoting from contents to names means closing, choosing another key, retyping the query.
