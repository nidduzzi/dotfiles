THE MOVE THIS BUYS
You grep validateToken, see it is defined somewhere you do not recognise, and press <Tab>. The same word is now matching file names. No closing, no retyping. The reverse pivot, names to contents, is the same keystroke.
FOR IT
One key to learn instead of four. The target becomes visible rather than remembered, and pivoting costs one keystroke instead of a restart.
AGAINST IT
Every non-default target costs a Tab you did not pay before, and muscle memory for <leader>ff is real. Tab is snacks' multi-select, so that has to move.
