Say it in the query
No chords at all. Scope and target are words you type, the way a search engine takes them.
GRAMMAR
validateToken
contents, the default
path:src/** token
only under src
!path:docs/** token
everywhere but docs
ext:lua,ts token
only those extensions
'token.expiry
literal, no regex
docs: rate limit
the prose instead of the code
❯ path:src/** validateToken 3/3
path: · ext: · docs: · ! to invert · ' for literal
FOR IT
Nothing to memorise beyond a hint line that is always on screen, and it composes: scope and term in one breath, no reaching for Alt. Familiar from every search box you already use.
AGAINST IT
The query is a regex, and prefixes are characters a regex may contain: searching for ' or a literal path: now needs an escape rule. More typing than a chord for the repeat case.
