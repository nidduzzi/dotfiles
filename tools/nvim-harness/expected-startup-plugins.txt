# Plugins loaded by the time the editor is sitting at the dashboard.
#
# lazy.nvim loads a plugin when it is first needed, so a plugin here is one
# that something asked for at startup. Each is deliberate: the colourscheme,
# the statusline and tabline, the picker the dashboard is drawn by, the
# treesitter layer the first file needs, and the plugins LazyVim itself wires
# into its own startup.
#
# A name appearing here that nobody added is an accident -- a lazy spec that
# lost its event or its keys -- and the editor looks identical either way. It
# just takes longer to open.
#
